## 🕳️ Gaps — incomplete / broken from the user's view

- **Drive Co-Pilot game unusable on fresh install** · `db/seeds.rb`, `lib/tasks/trivia.rake:3` · data · 19.4
  `db:seed` runs `QuizQuestion.rebuild!` but never `trivia:seed`, so `TriviaQuestion` is empty and `TriviaPool` falls back to a hardcoded **2-question** GENERIC list forever. → Add `Rake::Task['trivia:seed'].invoke` to `db/seeds.rb` (already idempotent).
- **Planning levers (pace/budget/preferences/transport_mode) locked after wizard** · `trips_controller.rb:287`, `trips/_form.html.erb` · code · 15.68
  Wizard collects them, Assembler reads them, DB has the columns — but `trip_params` doesn't permit them and the edit form has no fields, so a rebuild silently reuses the originals. → Permit + expose the four fields. (Finding #24 is the rebuild-side symptom of the same hole.)
- **Trip brief lazy-frame has no error state** · `trips_controller.rb:141`, `trips/show.html.erb:165` · code · 13.5
  `DestinationBrief.call` has no rescue; a 5xx loads the Rails error page *inside* the frame (frame-timeout only catches network errors, not HTTP 500). → `rescue` → render an empty/collapse partial.
- **Wizard `highlights_results` has no rescue** · `trips/wizard_controller.rb:82` · code · 13.5
  Same failure mode on the wizard's highlights frame; the "Skip & continue" escape only helps if the user scrolls past the broken frame. → `rescue` → friendly in-frame error pointing at Skip.
- **Day-trip suggestions frame: no fallback on non-timeout exceptions** · `day_trips_controller.rb:41`, `day_trips/suggestions.html.erb:87` · code · 10.8
  Same 5xx-in-frame pattern for `NearbyIdeas.call`. → `rescue` → in-frame error partial.
- **Photo upload/delete parity** · `trips/plan.html.erb:493`, `activity_photos_controller.rb:8` · code · 9.5
  "Add photo" shows to all members (`create` = `:show?`) but delete needs `:update?`, so a plain member can upload a photo they can't remove. → Gate the upload button behind `editable_by?` (or allow member delete).
- **`MathChainGenerator` / `seed_math_bulk` is dead code** · `app/services/math_chain_generator.rb`, `lib/tasks/trivia.rake:972` · code · 9.3
  Generators for up to 1000 math + topic questions exist but are reachable from no path and undocumented. → Document or add a `trivia:seed_all` alias.

## 🚀 Trends — emerging tech to adopt (with how-to)

> ⚠️ **Note on the subscription rule:** items 1, 3, 5 below optimize the app's **metered `anthropic` provider** (prompt caching / Haiku swap / adaptive thinking). They pay off only while in-app AI stays on the Anthropic *API*. If you move all in-app AI to `claude_cli` (subscription, but minutes-slow), these become moot — a real strategic fork worth deciding. Items 2 & 4 are stack upgrades, unaffected.

- **Prompt caching on `trip_concierge.v1` + `trip_structure.v1` system prompts** · `ai/anthropic_provider.rb` · code · 14.72
  ~1,400 static tokens re-sent every build/question. → `cache_control: {type: ephemeral, ttl: '1h'}` on the system block; ~90% input-token saving per hit. [prompt-caching docs](https://platform.claude.com/docs/en/build-with-claude/prompt-caching)
- **Turbo 8 morphing + `broadcasts_refreshes` on `trips/show`** · `trip.rb`, `activity.rb`, `show.html.erb` · code · 14.4
  Presence + Solid Cable already wired; collaborator edits currently need a reload or full-frame replace. → `broadcasts_refreshes` + `turbo_refreshes_with method: :morph, scroll: :preserve`; mark inline-edit inputs `data-turbo-permanent`. GA in turbo-rails. [turbo page-refreshes](https://turbo.hotwired.dev/handbook/page_refreshes)
- **Haiku 4.5 for `activity_narration.v1` + `destination_brief.v1`** · DB `model` field, zero-code · config · 12.3
  30 narrations/trip on Sonnet; Haiku 4.5 ≈ Sonnet-4 quality at ⅓ cost / ~2× speed for these tight JSON outputs. → flip model in `/admin/ai_prompts`, A/B 50. **Keep `trip_structure.v1` on Sonnet.** [haiku-4-5](https://www.anthropic.com/news/claude-haiku-4-5)
- **CSS View Transitions (shared-element morph) card → detail** · layout + index + show · code · 10.44
  Baseline since Oct 2025. → `<meta name=view-transition>` + matching `view-transition-name: trip-hero-<id>`; gate out of Hotwire Native. [view-transitions baseline](https://web.dev/blog/same-document-view-transitions-are-now-baseline-newly-available)
- **Adaptive thinking on `trip_structure.v1`** · `anthropic_provider.rb` · code · 9.36
  The most constraint-heavy prompt sends no `thinking` param. → `thinking: {type: adaptive}`, `output_config: {effort: medium}` (off-request, so latency is fine). [adaptive-thinking](https://platform.claude.com/docs/en/build-with-claude/adaptive-thinking)
- **Solid Queue fiber-mode workers for `NarrateActivityJob`** · `config/solid_queue.yml` · config · 9.0
  30 near-pure-I/O jobs/trip each hold a thread + DB slot today. → a `fibers: 50, processes: 1` worker for the narration queue. [solid-queue fibers](https://paolino.me/solid-queue-doesnt-need-a-thread-per-job/)

## Strategic notes

1. **One dominant, cheap theme: accessibility/contrast.** ~20 of 40 findings are AA contrast or missing-label/ARIA issues, nearly all effort-1, almost all violating the app's *own* `DESIGN_SYSTEM.md`. A single focused a11y pass (the Quick-wins table) clears most of the backlog and is ideal for the `--apply` path. Consider adding a CI lint (e.g. an erb-lint rule or a grep gate) to stop `slate-500/600` readable text and placeholder-only labels from re-entering.
2. **`db:seed` doesn't fully provision the product** (#2, #36): a fresh install has a broken Drive Co-Pilot. Highest-impact one-liner here.
3. **The post-wizard edit surface is thin** (#5/#24): users can't change pace/budget/preferences after creation — a genuine product gap, not just polish.
4. **Best new feature to build:** the **road-trip fuel/drive-time estimator** — highest competitor score, all-free data sources (OSRM + EIA), and it lights up the `transport_mode` + Co-Pilot machinery you already have.
5. **The AI-cost vs. subscription fork** (Trends note): decide whether in-app AI lives on the metered Anthropic API (then caching/Haiku/thinking pay off) or fully on `claude_cli` subscription (slower, but flat-cost).
6. **Blind spot:** still no product analytics, so none of this is weighted by real user drop-off. Adding Ahoy unlocks a 5th `funnel-analyst` lens (see `README.md`).
